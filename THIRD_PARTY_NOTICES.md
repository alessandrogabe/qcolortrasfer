# Third-party notices and inspirations

qcolortrasfer is an independent MIT-licensed implementation.

## Decimen Optical Transfer

Project: https://github.com/bashalarmistalt/decimen-optical-transfer

qcolortrasfer is inspired by Decimen's browser-based optical file-transfer experiments and by the use of rateless/fountain-coded visual frames. No source code from Decimen releases licensed under AGPL-3.0-or-later is incorporated in qcolortrasfer.

Decimen releases through v0.3.0 were published under the MIT License. If any code from those historical MIT releases is ever incorporated, the exact files and provenance must be documented here before merge.

## libcimbar

Project: https://github.com/sz3/libcimbar

qcolortrasfer is inspired by libcimbar's research and implementation approach for dense visual transfer using color and visual symbols. libcimbar is MPL-2.0 licensed. No libcimbar source code is incorporated in the current qcolortrasfer baseline.

## Wirehair

Project: https://github.com/catid/wirehair

Wirehair is a BSD-3-Clause fountain/erasure coding library considered for a future optional high-performance backend. It is not included in the current baseline.
